Matrix Chain Multiplication & Optimal Substructure

REF: CLRS CAP. 15.2

1. Principle of Optimality

Let a sequence of matrices ⟨A1, A2, ..., An⟩ where matrix Ai has dimensions pi-1 × pi. An optimal parenthesization of the product A1A2...An that splits at Ak contains within it optimal parenthesizations of the subchains A1..Ak and Ak+1..An.

2. Memoized Implementation (Python 3.12) 
# Optimal Memoized Chain Evaluation with Split Tracking
def memoized_matrix_chain(p: list[int]) -> tuple[list[list[float]], list[list[int]]]:
    n = len(p) - 1
    m = [[float('inf')] * (n + 1) for _ in range(n + 1)]
    s = [[0] * (n + 1) for _ in range(n + 1)]
    
    def lookup_chain(i: int, j: int) -> float:
        if m[i][j] < float('inf'):
            return m[i][j]
        if i == j:
            m[i][j] = 0
        else:
            for k in range(i, j):
                q = lookup_chain(i, k) + lookup_chain(k + 1, j) + p[i - 1] * p[k] * p[j]
                if q < m[i][j]:
                    m[i][j] = q
                    s[i][j] = k
        return m[i][j]

    lookup_chain(1, n)
    return m, s
